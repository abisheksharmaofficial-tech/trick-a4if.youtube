# Security Policy

## Supported Versions

Active development and security updates are maintained on the `main` branch of `trick-a4if.youtube`.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities or sensitive credential disclosures.

When reporting an issue, include:
- A clear description of the vulnerability and affected file or component.
- Steps to reproduce or proof-of-concept details.
- Potential impact and any suggested mitigation.

## Responsible Disclosure

Reports are reviewed promptly so fixes can be prepared and coordinated before public disclosure.
